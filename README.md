
# Shooter game
This project is a dynamic shooting game—developed in HTML, CSS, and JavaScript—where the player must aim and shoot crows. Each successful shot increases the score, while the difficulty increases with the speed of the birds. Don't let any crows escape, or it's game over!

## User Guide
Aim at the crows with your **mouse**, then click to shoot them down. If you miss a crow, it's game over!
